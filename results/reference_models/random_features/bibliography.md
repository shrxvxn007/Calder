# Bibliography and source verification

Verification date: 3 November 2026. Primary sources are used below. Bibliographic verification is distinct from reproducing a paper's complete experimental protocol.

1. Rubbi, A., Merchant, A., Ogden, S., Akbarnejad, A., Liò, P., Vakili, S., and Lotfollahi, M. (2026). *Many Needles in a Haystack: Active Hit Discovery for Perturbation Experiments*. arXiv:2605.10196, version 1, 11 May 2026. [Paper](https://arxiv.org/abs/2605.10196), [DOI](https://doi.org/10.48550/arXiv.2605.10196). The abstract and metadata were accessible. The paper motivates posterior threshold-exceedance probabilities for hit discovery. CALDER's Probability-of-Hit baseline is independently implemented and does not claim reproduction of the complete published protocol or its theoretical guarantees.

2. Miller, H. E., Mejia, G. M., Leblanc, F. J. A., Swain, B., Wang, B., and de Lima Camillo, L. P. (2026). *Deep learning perturbation models can outperform baselines on calibrated metrics*. Nature Biotechnology, online 1 October 2026. [Article](https://www.nature.com/articles/s41587-026-03307-w), [PubMed record 42823510](https://pubmed.ncbi.nlm.nih.gov/42823510/), [DOI](https://doi.org/10.1038/s41587-026-03307-w). The initial direct Nature request redirected to an inaccessible identity endpoint; the indexed Nature article and PubMed abstract verified the reference. This work concerns the sensitivity and calibration of evaluation metrics. That concept differs from CALDER's calibration of predicted hit probabilities. Neither finding implies that calibration must improve an acquisition trajectory.

3. Peidli, S., Green, T. D., Shen, C., et al. (2024). *scPerturb: harmonized single-cell perturbation data*. Nature Methods 21, 531–540. [Article](https://www.nature.com/articles/s41592-023-02144-y), [PubMed record 38279009](https://pubmed.ncbi.nlm.nih.gov/38279009/), [author manuscript](https://pmc.ncbi.nlm.nih.gov/articles/PMC12220817/), [code](https://github.com/sanderlab/scPerturb). Publication date 26 January 2024; the DOI's 2023 component is not its publication year. The resource harmonizes experimental annotations and supports distributional comparisons including E-statistics. CALDER's main weighted pseudobulk magnitude is an independently defined within-dataset response score.

4. scPertEval. *Datasets*, accessed 3 November 2026. [Documentation](https://scperteval.readthedocs.io/en/latest/user-guide/datasets.html). The documentation lists `replogle22k562` and `replogle22rpe1` and the public GCS processed-file pattern. It identifies these as the essential-gene panel rather than the much larger K562 genome-wide screen. Dataset counts quoted there are source metadata, not CALDER's retained sample counts. File availability, checksum, actual schema and normalization must be checked separately for each local download.

5. STRING consortium. *STRING functional protein association networks*, version 12.5 displayed at verification. [Service](https://string-db.org/), [help](https://string-db.org/cgi/help). STRING edges describe protein associations and may include indirect evidence. Network communities are therefore called **network modules**, never established causal pathways. A user-supplied versioned human-network file and explicit identifier mapping are required for reproducible local network features.

6. Replogle, J. M., et al. (2022). *Mapping information-rich genotype-phenotype landscapes with genome-scale Perturb-seq*. Cell 185, 2559–2575.e28. [DOI](https://doi.org/10.1016/j.cell.2022.05.013). Primary study for the Replogle essential-gene perturbation datasets, linked by the scPertEval dataset documentation. Cite the original experimental authors when reporting retrospective biological results.

7. Peidli, S., Green, T. D., Shen, C., et al. (2022; release 1.4). *scPerturb Single-Cell Perturbation Data: RNA and protein h5ad files*. Zenodo. [Record 13350497](https://zenodo.org/records/13350497), [DOI](https://doi.org/10.5281/zenodo.13350497). This release provides an alternative harmonized source for the exact Replogle K562 essential and RPE1 panels. The public record API and file HEAD requests were verified on 3 November 2026. Preparation must validate this source's own annotation schema and expression scale; it is not the scPertEval processed release. Download checksums and sizes are recorded separately in data manifests.

## Verification limits

No result from these sources is imported into CALDER's experiment tables. The code does not recreate another paper's unpublished implementation choices. Source metadata do not establish successful local download or preprocessing; those facts belong to the run manifests. Raw and processed data can change independently of documentation, so checksums are part of data provenance.
